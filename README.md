# 🛍️ FetchStore App

A simple frontend eCommerce web application built using **HTML, CSS (Bootstrap), and JavaScript**.
This project demonstrates real-world development practices including **Fetch API**, **Git workflow**, and **feature-based branching**.

---

## 🚀 Features

* 🔐 User Login (Basic validation with LocalStorage)
* 📦 Product Listing using Fetch API
* 🔍 Product Detail Page
* 🔄 Page Navigation (Login → Home → Product)
* 🌿 Git Branching Strategy (main, develop, feature branches)

---

## 🛠️ Tech Stack

* HTML5
* CSS3 (Bootstrap)
* JavaScript (Vanilla JS)
* Fetch API
* Git & GitHub

---

## 📡 API Used

* https://fakestoreapi.com/products
